## Lesson 2 - What is data structure

Data structure is an organized structure inside the computer memory or in any storing device, in a way that the data can
be used correctly.

Imagine we need to organize the data in memory. Our memory is volatile and we need to organize it through structures.

Imagine a city. In a city we have streets, neighborhoods, buildings, and so on. We can see them as organizational structures.
And To organize this data. in a way that this data can be handled and used correctly, we have the data structures.

They can be organized either on memory or in any storage device, like flash disks, external HD, cloud, and more.

These structures can be general or very specific to certain tasks. Using the correct ones, we can work with large or small
set of data

In a data structure, we should know how to perform a set of basic operations, like:

Inserting Data
Deleting Data
Locating An Element
Run through every item on the structure
Classify, which means putting the data items in a given order

The main data structures are

1D Array - Vectors
2D Array = Matrix
ND Array - Arrays with three or more dimensions
